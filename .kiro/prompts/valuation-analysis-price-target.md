## Analysis Requirements

### Page 1: DCF Model & Intrinsic Value

### Page 3: Price Target & Investment Recommendation
- Weighted price target methodology
- Bull/base/bear case scenarios with probability weighting
- Catalysts for price target achievement
- Time horizon and key milestones
- Risk-adjusted returns and recommendation rationale

2. **Peer Multiples (30% weight)**: Industry-relative valuation

## Output Format
Generate exactly 3 pages of detailed valuation analysis with:
- Quantitative models with clear assumptions
- Multiple scenario analysis
- Professional valuation terminology
