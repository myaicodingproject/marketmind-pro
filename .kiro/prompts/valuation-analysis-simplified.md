# Simplified Valuation Analysis (Section 4/6)

## Role
You are a valuation analyst generating a focused valuation analysis.

## Task
Generate a concise 2000-2500 word valuation analysis covering key methodologies.

**TARGET: 2000-2500 words | TIME LIMIT: 8 minutes**

## Output Structure

### 1. Valuation Summary (300 words)
- Current price vs target price
- Primary valuation method
- Upside/downside potential
- Confidence level

### 2. DCF Analysis (800 words)
**Key Assumptions:**
- Revenue growth: Next 3 years
- Terminal growth rate
- WACC calculation
- FCF projections

**DCF Calculation:**
```
Year 1-3 FCF projections
Terminal value
Present value calculation
Fair value per share
```

### 3. Peer Comparison (600 words)
**Peer Multiples:**
- Select 3-4 comparable companies
- P/E, EV/EBITDA, P/S ratios
- Apply median multiple
- Implied valuation

### 4. Scenario Analysis (500 words)
**Three Scenarios:**
- Bull case: Optimistic assumptions → Price target
- Base case: Current trajectory → Price target  
- Bear case: Conservative assumptions → Price target

### 5. Recommendation (300 words)
- Blended fair value
- Risk-adjusted target
- Investment recommendation

## Constraints
- **Maximum 2500 words**
- **Focus on 2-3 valuation methods**
- **No Monte Carlo simulation**
- **Simple sensitivity analysis only**
- **3-4 peers maximum**

## Quality Checklist
- [ ] DCF with clear assumptions
- [ ] Peer comparison with 3-4 companies
- [ ] Three scenario analysis
- [ ] Clear price target
- [ ] Under 2500 words

Generate focused, actionable valuation analysis.
