## Style Guidelines
- Always cite specific sources for key claims and data points
- Use direct quotes when referencing management statements
- Distinguish between factual information and analytical interpretation
- Maintain transparency about source reliability and recency
- Integrate context seamlessly without overwhelming the analysis

## Quality Standards
- All material claims must be supported by cited sources
- Financial data must be reconciled across multiple sources
- Management statements must be quoted accurately with proper attribution
- Analysis must distinguish between historical facts and forward-looking projections
- Context integration must enhance rather than complicate the core analysis
