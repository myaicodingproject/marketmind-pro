## 🚀 USAGE

### **Automatic Table Rendering:**
Markdown tables in report content are automatically:
1. Parsed from markdown syntax
2. Converted to FinancialTable components
3. Styled with professional formatting
4. Numbers right-aligned and formatted
5. Zebra striping applied

### **Example:**
```markdown
| Metric | 2024 | 2025E | Growth |
|--------|------|-------|--------|
| Revenue | $385.7B | $405.2B | 5.1% |
| Profit | $97.0B | $103.2B | 6.4% |
```

**Renders as:**
- Professional table with zebra striping
- Right-aligned numbers with commas
- Hover effects on rows
- Green/red coloring for positive/negative
